## Ask for something real

Light Code works in steps: one tool call at a time, with the result in front of you, until the
job is done or it needs you.

Good first asks:

- *"What does this project do? Read the README and summarise it."*
- *"Find every place we parse dates and list the files."*
- *"Add a test for the empty-input case in `parse()`."*

**Giving it context**

- Type `@` to attach a file or folder by name.
- Drop or paste any file into the composer — images go to vision-capable models, everything
  else is read as text and included with your message.
- It reads **Word, Excel, HTML and PDF** as text, and can page through a large log file rather
  than swallowing it whole.

**Keeping track**

- The bar under the composer shows what is filling the context window — system prompt, tool
  definitions, conversation, results — with the cache hit rate.
- Conversations survive closing the panel, reloading the window, and restarting VS Code.
  The clock icon opens your history.
- **Modes** sit in the header: *Code* can do everything, *Ask* is read-only.
