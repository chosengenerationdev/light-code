# Light Code

A minimal agentic coding assistant for VS Code. Chat UI, a small set of built-in agent
tools, configurable LLM providers, MCP tool integration, and image attachments — and
deliberately nothing else.

Status: early scaffold. Not yet usable. See `IMPLEMENTATION_PLAN.md` for the build order
and `CLAUDE.md` for the design decisions behind it.

License: MIT. No telemetry, ever.
