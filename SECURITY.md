# Security Policy

If you find a security issue in Light Code, please report it privately rather than opening
a public issue: chosen.generation.dev@gmail.com

Include the version, platform, and reproduction steps. We'll acknowledge within a few days.

See `CLAUDE.md` §3 for what the security boundary does and does not cover — Light Code
does not sandbox executed code (shell commands, MCP servers, Python tools), and reports
about that inherent behavior (rather than a bug in it) will be closed as by design.
